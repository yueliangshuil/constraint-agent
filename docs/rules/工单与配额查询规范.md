# 工单与配额查询规范

## 规则七：紧急工单审批
- ruleType: precondition
- priority: 3
- forbidAction: create_change_ticket
- expression: isEmergency && !approvedByDirector

创建紧急变更工单需总监审批。

## 规则八：配额查询时间
- ruleType: time
- priority: 2
- forbidAction: query_quota
- expression: !isWorkday || hour < 9 || hour >= 18

配额查询仅限工作时间。
