# 生产环境发布规范

## 规则一：发布时间窗口
- ruleType: time
- priority: 3
- forbidAction: deploy_service
- expression: env == "prod" && isWorkday && (hour >= 22 || hour < 6)

工作日 22:00 至次日 06:00 禁止生产环境发布。

## 规则二：发布权限
- ruleType: permission
- priority: 4
- forbidAction: deploy_service
- expression: env == "prod" && (role == "intern" || role == "junior")

生产环境发布需要 senior 及以上角色。

## 规则三：发布配额
- ruleType: quota
- priority: 3
- forbidAction: deploy_service
- expression: quotaUsed >= quotaLimit

单个服务单日发布次数不超过 3 次。

## 规则四：变更工单
- ruleType: precondition
- priority: 2
- forbidAction: deploy_service
- expression: env == "prod" && !hasTicket

生产环境发布必须关联变更工单。
